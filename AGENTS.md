# AGENTS.md

See `CLAUDE.md`. It is the single set of agent instructions for this
repository — the two-plane rule (`llm/` control plane, `docs/` data
plane), the Q1/Q2 pre-write decision procedure, the tool-contract
exemption class, and the output-location preferences for design specs
and implementation plans.

This file exists because some tools read `AGENTS.md` rather than
`CLAUDE.md`. It restates no policy of its own; `CLAUDE.md` is the only
copy.
